7. 저장소 디렉토리 구조 및 핵심 아티팩트

프로젝트 형상 관리를 위한 디렉토리 계층 구조, 4대 필수 문서(아키텍처, 증빙, 트러블슈팅, 체크리스트), 인프라 자동화 스크립트 및 IAM 최소권한 정책 파일의 역할을 총람합니다.

📁 전체 디렉토리 트리 뷰 (Directory Tree)

ilikeaws/ ├── README.md # 프로젝트 종합 가이드 및 동료평가 루브릭 체크표 ├── README.html # 프로젝트 통합 시각화 대시보드 ├── Dockerfile # 보너스 과제용 Docker 빌드 명세서 (Alpine Nginx) ├── docker-compose.yml # Docker Compose 단일 컨테이너 실행 명세 ├── docs/ │ ├── architecture.png # [필수 1] 아키텍처 다이어그램 고해상도 PNG │ ├── architecture.pdf # [필수 1] 아키텍처 다이어그램 PDF 문서 │ ├── architecture.svg # 아키텍처 원본 벡터 그래픽 (확대 왜곡 없음) │ ├── architecture.md # 인프라 명세 및 트래픽 흐름 상세 설명서 │ ├── troubleshooting.md # [필수 3] 트러블슈팅 보고서 (4대 실무 사례) │ ├── troubleshooting.pdf # [필수 3] 트러블슈팅 보고서 PDF 문서 │ ├── cleanup-checklist.md # [필수 4] 리소스 정리 체크리스트 및 과금 방지 보고서 │ └── screenshots/ # [필수 2] 외부 접속 및 상태 검증 스크린샷 갤러리 │ ├── 01-web-browser.png # 브라우저 외부 접속 증빙 화면 (http://54.180.1.48) │ ├── 02-health-check.png # GET /health 200 OK 및 아웃바운드 인터넷 통신 증빙 │ ├── 03-docker-ps.png # 보너스 과제 2: docker ps 컨테이너 가동 증빙 화면 │ └── 04-cleanup-verified.png # 리소스 완전 삭제 0건 검증 화면 ├── iam/ │ └── minimal-deployer-policy.jsonl # IAM 최소권한 정책 정의 JSON (화이트리스트+Deny) ├── scripts/ │ ├── setup-aws.sh # AWS 리소스 자동 프로비저닝 쉘 스크립트 │ ├── cleanup-aws.sh # AWS 리소스 안전 역순 일괄 정리 스크립트 │ └── deploy-docker.sh # 보너스 Docker 배포 자동화 스크립트 └── web/ ├── index.html # 웹 서비스 메인 대시보드 화면 (HTML) ├── health # /health 고정 응답 텍스트 ("OK") └── nginx.conf # Nginx 가상 호스트 및 엔드포인트 라우팅 설정

🔑 핵심 보안 아티팩트: IAM 최소권한 정책 명세

iam/minimal-deployer-policy.jsonl: AdministratorAccess를 부여하지 않고 실습에 필수적인 EC2/VPC API만 선별 허용하며, 무관한 S3, RDS, DynamoDB, Lambda 등은 명시적으로 차단(Explicit Deny)한 교과서적 정책입니다. 

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "EC2AndVPCOperationsLeastPrivilege",
      "Effect": "Allow",
      "Action": [
        "ec2:CreateVpc", "ec2:DeleteVpc", "ec2:DescribeVpcs", "ec2:ModifyVpcAttribute",
        "ec2:CreateSubnet", "ec2:DeleteSubnet", "ec2:DescribeSubnets", "ec2:ModifySubnetAttribute",
        "ec2:CreateInternetGateway", "ec2:DeleteInternetGateway", "ec2:AttachInternetGateway", "ec2:DetachInternetGateway",
        "ec2:CreateRouteTable", "ec2:DeleteRouteTable", "ec2:CreateRoute", "ec2:AssociateRouteTable",
        "ec2:CreateSecurityGroup", "ec2:DeleteSecurityGroup", "ec2:AuthorizeSecurityGroupIngress",
        "ec2:AllocateAddress", "ec2:ReleaseAddress", "ec2:AssociateAddress",
        "ec2:RunInstances", "ec2:TerminateInstances", "ec2:DescribeInstances", "ec2:CreateTags"
      ],
      "Resource": "*"
    },
    {
      "Sid": "DenyUnrelatedServices",
      "Effect": "Deny",
      "Action": [
        "s3:*",
        "rds:*",
        "dynamodb:*",
        "lambda:*",
        "iam:CreateUser",
        "iam:AttachUserPolicy"
      ],
      "Resource": "*"
    }
  ]
}

📦 서브 디렉토리별 역할 및 구성 요소

📁 docs/

아키텍처 다이어그램(PNG/PDF/SVG), 트러블슈팅 보고서, 리소스 정리 체크리스트 및 실제 접속 캡처 보관소

4대 필수 결과물 일체
📁 scripts/

setup-aws.sh (자동 구축), cleanup-aws.sh (역순 완전 삭제), deploy-docker.sh (컨테이너 배포) 쉘 스크립트

AWS CLI 자동화 엔진
📁 web/

메인 인프라 대시보드(index.html), 로드밸런서용 고정 응답(health), Nginx 포트 및 라우팅 설정(nginx.conf)

웹 애플리케이션 계층
📁 iam/

최소 권한 원칙(Least Privilege)을 실현한 mission-deployer 전용 정책 정의 파일 보관
