4. ⭐ 보너스 과제 2 — Docker 컨테이너로 배포

호스트 OS에 종속되지 않는 일관된 실행 환경을 보장하기 위해, 경량 Alpine Nginx 기반 Docker 이미지를 빌드하고 포트 바인딩(80:80) 및 자동 재시작 정책을 적용하여 컨테이너 웹 서비스를 배포했습니다.

🐳 컨테이너 가동 증빙 및 스펙

🔍 원본 확대

docker ps 가동 상태 증빙

ilikeaws-web:latest 컨테이너가 0.0.0.0:80->80/tcp로 정상 포워딩되어 Up (healthy) 상태로 유지 중임을 터미널 명령어로 입증합니다.

# 1. Docker 이미지 빌드
$ docker build -t ilikeaws-web:latest .

# 2. 백그라운드 무중단 컨테이너 실행
$ docker run -d \
  --name ilikeaws-web-server \
  -p 80:80 \
  --restart always \
  ilikeaws-web:latest

# 3. 컨테이너 헬스체크 검증
$ curl -i http://localhost/health
HTTP/1.1 200 OK
OK
베이스 이미지
nginx:alpine (초경량)
포트 매핑
Host 80 ➔ Container 80
재시작 정책
restart: always
빌드 자동화
docker-compose.yml 완비

📄 Dockerfile & Compose 구성 명세

Dockerfile 명세

FROM nginx:alpine

# 웹 정적 파일 및 헬스체크 파일 복사
COPY web/index.html /usr/share/nginx/html/index.html
COPY web/health /usr/share/nginx/html/health

# Nginx 커스텀 라우팅 설정 파일 복사
COPY web/nginx.conf /etc/nginx/conf.d/default.conf

# 웹 포트 노출 및 데몬 포그라운드 실행
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

docker-compose.yml 명세

services:
  web:
    build: .
    image: ilikeaws-web:latest
    container_name: ilikeaws-web-server
    restart: always
    ports:
      - "80:80"
